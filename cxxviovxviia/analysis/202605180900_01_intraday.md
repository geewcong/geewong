## 二、核心驅動因素

### 油價 → 債息 → 股市（主線）

```
伊朗戰爭僵局
  → 霍爾木茲海峽實質關閉（流量僅正常4%）
    → WTI 原油逼近 $108/桶
      → 全球通脹壓力急升
        → 10年期美債息升到 4.623厘
        → 30年期升穿 5.146厘
          → 市場由「預期減息兩次」轉向「可能加息」
            → 股市估值受壓，全球下跌
```

### 觸發事件時間線

- **特朗普拒絕伊朗「14點」方案** — 話「第一句唔啱聽就掟掉」
- **霍爾木茲海峽流量跌到 4%**（80萬桶/日 vs 正常2,000萬）
- **IEA 數據：全球庫存以每日400萬桶速度減少** — 有記錄以來最快
- **Trump-Xi 會面** — 投資者未見到實質突破

## 三、板塊及個股焦點

### 理想汽車 (LI) — 今日最傷藍籌 -14%

**原因分析：**
1. **新車定價令人失望** — 升級版 L9 Livis 最終定價較預售價低7萬人幣，但花旗報告話性價比只係「同級看齊」
2. **基本面差** — 2025年交付量同比跌18.8%，由新勢力銷冠跌到第5；淨利潤暴跌99.4%，連續11季盈利紀錄斷纜
3. **產品內鬥** — L 系列同 i 系列價格重疊，互相蠶食
4. **純電轉型落後** — 押注增程太耐，錯失純電先發
5. **花旗潑冷水 + 大市弱 = 踩踏式拋售**

### 吉利汽車 — 逆市 +1.69%

**原因分析：**
1. **全品類佈局** — 銀河系列、極氪、領克等，唔靠單一產品線
2. **2026年銷量目標進取** — 345萬輛（+14%），新能源目標222萬輛（+32%）
3. **全球擴張** — 同 Ford 密談歐洲合作、Robotaxi 2027年量產、銀河星願係2025年最暢銷電動車
4. **估值吸引** — 利潤增長36%，有具體增長故事

### 其他板塊

- **科技股**：普遍受壓，納指相關股份跟跌
- **能源股**：油價高企利好，但整體氣氛差
- **內房**：債息上升 + 加息預期 = 借貸成本上升，受壓

## 四、韓股暴跌背景（影響港股氣氛）

### 事件：KOSPI 上週五（5/15）暴跌 6.12%

- 當日觸及 **8,046 歷史新高**，然後即日大逆轉收 **7,493**
- 外資單日淨沽出 5.6萬億韓元
- 韓圜跌穿 1,500 兌 1 美元

### 觸發點
1. 韓國政府提出「AI 利潤再分配」政策 — 市場擔心加稅
2. 估值過高 — KOSPI 一年升 200%，部分晶片股 PE 超過 100倍
3. 散戶槓桿極度膨脹 — 78%散戶使用超過40%槓桿，部分3倍

### 結構性問題
- 三星 + SK 海力士佔 KOSPI 權重 45%
- 70.7%原油要經霍爾木茲海峽進口
- 外資持股35%（T+0可即日走）
- 韓國 = 全球市場「金絲雀」

### 踩踏過程
```
外資獲利回吐 → 散戶恐慌 → 槓桿斬倉(margin call) → 程序化交易拋售(佔40%) → 惡性循環
```
