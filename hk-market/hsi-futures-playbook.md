## Part 1：基礎概念（Fundamentals）

### 1.1 期指係咩？

期指 = **期貨指數合約**，係一種預期恒生指數方向嘅衍生工具。

- **買入（Long）**：看好後市，升就賺
- **沽出（Short）**：看淡後市，跌就賺
- **零和遊戲**：一方賺 = 另一方輸，唔同股票大家都可以賺
- **可以即日買賣**：即日鮮，唔使過夜
- **現金交割**：唔同商品期貨（大豆、原油）可以實物交割，指數期貨只能現金結算
- **主要用途**：短線價差投機、風險對沖、套利

### 1.2 恒生指數 ≠ 恒生指數期貨

- **恒生指數（HSI）**：由多隻藍籌股計算出嚟嘅指數，**唔可以買賣**
- **恒生指數期貨（HSI Futures）**：可以買賣嘅合約，價格由市場決定
- 兩者走勢高度相關，但唔完全一樣

### 1.3 合約月份

同一時間有 4 個月份可以交易：

| 類型 | 說明 |
|------|------|
| 即月 | 當前月份，成交最活躍，最易預測 |
| 下月 | 下一個月份，成交較少 |
| 季月 | 之後嘅季月（3/6/9/12） |

例：5月可交易 → 5月、6月、9月、12月
到咗6月 → 6月、7月、9月、12月

合約代碼例子：即月 HSI2405 → 改為 HSI2406 就係下月

**新手建議：只交易即月，流動性最好。**

### 1.4 高水 / 低水

- **高水**：期指價 > 恒指現貨價 → 市場偏向看好
- **低水**：期指價 < 恒指現貨價 → 市場偏向看淡
- **注意**：業績公佈後（如滙控、長和）期指會大低水，因為已預期扣股息，唔代表真正看淡

### 1.5 結算

- **結算日**：每月倒數第二個交易日（即最後交易日）
- **結算價**：交易所根據結算日當天交易情況計算
- 如果你喺結算日前冇平倉，就會用結算價自動結算
- 結算價 > 買入價 = 買方獲利，反之虧損
- **現金結算**：盈虧以現金形式結算，冇實物交割

### 1.6 轉倉（Rollover / 展期）

如果你想繼續持有期指但即月快要結算，可以「轉倉」：
- 平倉即將到期嘅期指
- 同時買入下個月到期嘅期指
- 等於延長持倉週期，唔使被結算
- **注意**：轉倉會有買賣差價成本

## Part 2：交易規格（Specs & Mechanics）

### 2.1 大期 vs 細期

| | 大期（HSI） | 細期（MHI） |
|---|---|---|
| 每點價值 | HK$50 | HK$10 |
| 基本按金 | ~HK$80,000-100,000 | ~HK$16,000-20,000 |
| 適合對象 | 有經驗、資金較多 | 新手、資金較少 |
| 代號 | HSI | MHI |

### 2.2 交易時間（2026年最新）

| 時段 | 時間 |
|------|------|
| 日間 T時段 | 09:15 - 12:00, 13:00 - 16:30 |
| 夜間 T+1時段 | 17:15 - 03:00 |
| 最後交易日 | 收市 16:00 |

**夜期合約清單（富途支援）：**
- 恒指期貨及期權（含周期權）
- 小恒指期貨及期權（含周期權）
- 國指期貨及期權（含周期權）
- 小國指期貨及期權（含周期權）
- MSCI 相關指數期貨
- 美元黃金期貨

**注意**：夜盤交易算作 T+1 日嘅訂單。

### 2.3 按金制度

- **基本按金（Initial Margin）**：開倉必須有嘅最低金額
- **維持按金（Maintenance Margin）**：低過呢個水平就要補倉
- **補倉（Margin Call）**：經紀要求你加錢返到基本按金水平
- **斬倉（Forced Liquidation）**：唔補倉，經紀會強制平倉

**⚠️ 重點：按金唔係成本，係抵押。平倉後會退返（扣埋盈虧）。**

### 2.4 合約六大要素

每張期指合約包含：
1. **合約名稱/代碼**（如 HSI、MHI）
2. **標的指數**（如恒生指數）
3. **最後交易日**（結算日）
4. **合約規模**（大期每點$50、細期每點$10）
5. **最小變動單位**（1 點）
6. **初始保證金**（開倉所需金額）

### 2.5 落單類型

| 類型 | 說明 |
|------|------|
| 市價單（Market Order） | 以即時市場價成交 |
| 限價單（Limit Order） | 設定目標價，到價先成交 |
| 止損單（Stop Loss Order） | 觸及價位自動平倉止損 |
| 止賺單（Take Profit Order） | 觸及價位自動平倉鎖定利潤 |

## Part 3：市場指標解讀（Market Indicators）

### 3.1 大戶持倉

- **十大好友 / 十大淡友**：每週公佈，睇大戶部署
- **來源**：HKEX 網站 → 每日持倉報告
- **怎樣用**：如果好友倉位遠大於淡友，短期偏多；反之偏空
- **注意**：大戶之間都有角力，唔好盲目跟

### 3.2 未平倉合約（Open Interest, OI）

- OI 增加 + 價格升 → 新資金入場看好，趨勢健康
- OI 增加 + 價格跌 → 新資金入場看淡，跌勢可能持續
- OI 減少 + 價格升 → 空倉平倉推動，升勢未必持久
- OI 減少 + 價格跌 → 好倉平倉推動，跌勢未必持久

### 3.3 成交量

- 成交量配合趨勢 = 確認信號
- 突然放量 = 可能轉勢或加速

### 3.4 夜期參考

- 夜期反映外圍情緒（美股、A股消息）
- 夜期收市價 vs 日期收市價嘅差距 = 預期隔日開市方向
- **注意**：夜期成交較少，價格波動可能被誇大

## Part 4：技術分析入門（Technical Analysis）

### 4.1 K線形態（蠟燭圖）

**必學形態：**

| 形態 | 信號 |
|------|------|
| Doji（十字星） | 猶豫、可能轉勢 |
| Hammer（錘頭） | 底部反彈信號 |
| Shooting Star（射擊之星） | 頂部回落信號 |
| Engulfing（包吞） | 強烈反轉信號 |
| Morning/Evening Star | 反轉組合形態 |

### 4.2 支撐與阻力

- **支撐位**：價格跌到呢個位容易反彈（前低、整數關口、MA）
- **阻力位**：價格升到呢個位容易回落（前高、整數關口、MA）
- **整數關口**：20000、21000 呢啲位特別多人留意

### 4.3 移動平均線（MA）

| MA | 用途 |
|----|------|
| MA5 / MA10 | 超短線趨勢 |
| MA20 | 短線趨勢（月線） |
| MA50 | 中線趨勢 |
| MA250 | 長線趨勢（年線） |

**基本用法：**
- 價格喺 MA 之上 = 偏多
- 價格喺 MA 之下 = 偏空
- MA 點金叉（短MA上穿長MA）= 看好信號
- MA 死叉（短MA下穿長MA）= 看淡信號

### 4.4 RSI（相對強弱指數）

- 範圍 0-100
- **>70**：超買，可能回調
- **<30**：超賣，可能反彈
- **背馳**：價格创新高但 RSI 冇 = 轉勢信號

### 4.5 MACD

- MACD 線上穿信號線 = 看好
- MACD 線下穿信號線 = 看淡
- 柱狀圖由負轉正 = 動能轉強

## Part 7：風險管理（Risk Management）

### 7.1 新手鐵律

1. **一定設止損** — 冇例外
2. **模擬盤至少4週** — 連續盈利先轉實盤
3. **由細期開始** — MHI 每點 $10，入門門檻低
4. **唔好溝淡/加死碼** — 蝕緊錢唔好加倉
5. **唔好過夜** — 初期只做即日鮮
6. **情緒控制** — 輸咗唔好追，贏咗唔好貪

### 7.2 資金管理

- 期指係保證金交易，槓桿放大盈利同虧損
- 戶口入面嘅錢 > 按金 = 你有緩衝
- 唔好將所有資金放入期指戶口
- 建議：期指資金佔總投資資金 ≤ 20%

### 7.3 常見新手陷阱

| 陷阱 | 點避 |
|------|------|
| 唔設止損 | 每單必設，開倉同時設 |
| 過度交易 | 每日限制交易次數 |
| 溝淡 | 止損走人，唔好加碼 |
| 追升追跌 | 等回調先入 |
| 重倉 | 控制倉位比例 |

## 附錄：術語表（Glossary）

| 術語 | 英文 | 解釋 |
|------|------|------|
| 期指 | HSI Futures | 恒生指數期貨合約 |
| 大期 | HSI | 恒指期貨（每點$50） |
| 細期 | MHI | 小型恒指期貨（每點$10） |
| 高水 | Premium / Contango | 期指 > 恒指現貨（又叫升水） |
| 低水 | Discount / Backwardation | 期指 < 恒指現貨（又叫貼水） |
| 按金 | Margin | 開倉所需抵押金 |
| 補倉 | Margin Call | 帳戶資金低於維持按金 |
| 斬倉 | Forced Liquidation | 強制平倉 |
| 平倉 | Close Position | 结束持倉 |
| 轉倉 | Rollover | 平即月倉 + 開下月倉 |
| 即月 | Spot Month | 當前月份合約 |
| 結算 | Settlement | 合約到期結算（現金交割） |
| 即日鮮 | Day Trading | 即日開倉平倉 |
| OI | Open Interest | 未平倉合約數量 |
| 好友 | Bull | 看好後市 |
| 淡友 | Bear | 看淡後市 |
| 做多/買入 | Long | 看升 |
| 做空/沽出 | Short | 看跌 |
| 現金交割 | Cash Settlement | 只用現金結算，冇實物 |
