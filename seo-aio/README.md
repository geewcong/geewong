## Structure

```

│   └── YYYY-MM-DD.md
```

## Purpose

- Track Google algorithm updates & AI search evolution

- **Technical SEO** — Schema markup, site architecture, crawlability
- **E-E-A-T** — Expertise signals, author entities, trust building
- **Agency Strategy** — Service packaging, pricing, client deliverables
