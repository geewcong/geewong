## 一、聯儲局加息預期 — 由「減息」到「可能加息」

### 發生咗咩事？

| 時間 | 市場預期 |
|------|---------|
| 2026年2月前 | 今年減息兩次 |
| 2月（伊朗戰爭爆發） | 開始動搖 |
| 4月（PPI創2022年來最快） | 減息無望 |
| 5月（債息飆升） | 開始 price in 加息 |

### 關鍵數據
- **10年期美債息：4.623厘**（近一年高位）
- **30年期美債息：5.146厘**（破5%）
- **批發通脹 PPI：** 2022年以來最快增速
- **DoubleLine CEO Gundlach：** 減息「根本不可能」
- **Morningstar：** 「呢個圖係閃爍嘅警告信號 — 聯儲局可能年底前加息」

### 加息影響鏈

```
油價高企
  → 通脹壓力加劇
    → 聯儲局被迫加息（或至少唔減）
      → 債息上升
        → 企業借貸成本上升（盈利受壓）
        → 股市估值被壓縮（高PE股最傷）
        → 樓按利率上升（消費者支出減少）
        → 美元走強（新興市場資金外流）
```

### 對港股具體影響

| 層面 | 機制 | 受影響板塊 |
|------|------|-----------|
| 高PE科技股 | 折現率上升 = 估值下調 | 理想、美團、快手 |
| 港元/美元掛鈎 | 被動跟加 | 地產、零售、消費 |
| 北水流向 | 人幣貶值+中美利差擴大 | 整體流動性 |
| 高負債企業 | 借貸成本直接上升 | 內房、高負債國企 |

### Ruga 判斷
唔係聯儲局真係會即刻加息，而係「市場預期由減息轉向加息」呢個心理轉變本身已經足以殺傷股市。呢個預期會持續壓住估值，直至油價回落或通脹明確降溫。

## 二、韓股 KOSPI 暴跌事件拆解

### 事件概要
- **日期：** 2026年5月15日（上週五）
- **KOSPI 當日走勢：** 歷史新高 8,046 → 收 7,493（**-6.12%**，跌488點）
- **外資：** 單日淨沽出 5.6萬億韓元
- **韓圜：** 跌穿 1,500 兌 1 美元

### 三重觸發

**1. 政策面：**
- 韓國高官提出「AI Profit Redistribution」（AI利潤再分配/國民紅利）
- 市場解讀為對半導體企業加稅/增加負擔

**2. 估值面：**
- KOSPI 過去一年升 **200%**
- 部分晶片股市盈率超 **100倍**
- 三星 PE 6倍 vs 英偉達 22倍 vs 部分韓國小市值晶片股 100倍+

**3. 資金結構面（最大隱患）：**
- 韓國每3個人就有1個炒股
- **78%散戶使用超過40%槓桿**，部分達 **3倍**
- 融資餘額 **34萬億韓元**（歷史新高）
- 券商開始上調保證金要求
- 外資持股 35%，享有 T+0 交易

### 韓國結構性弱點

**產業過度集中：**
- 三星 + SK 海力士佔 KOSPI 權重 **45%**
- 半導體出口佔韓國總出口 **1/3**
- 全球80%高端 HBM 晶片產能集中於此

**能源脆弱性：**
- **70.7% 原油** 要經霍爾木茲海峽進口
- **29% 液化天然氣** 要經霍爾木茲海峽
- **64.7% 氦氣**（晶片冷卻關鍵）依賴卡塔爾
- 若海峽長期封鎖：煉油廠30天內斷供，半導體工廠面臨停產

### 踩踏機制

```
外資獲利回吐（觸發點：AI利潤再分配政策）
  → 指數由8,046回落
    → 散戶恐慌
      → 槓桿盤被迫斬倉（margin call）
        → 程序化交易（佔40%）自動拋售
          → KOSPI 跌 8% → 10% → 12%...
            → 更多斬倉 → 惡性循環
```

### Financial Post 現場報道
> 「散戶望住手機見到虧損不斷擴大 — KOSPI 跌 8%，然後 10%，然後 12% — 恐慌蔓延。」

### 韓國 = 全球「金絲雀」
- 對全球風險反應最敏感
- 3月初霍爾木茲危機時，韓股**兩日暴跌18%**，市值蒸發300萬億韓元
- 韓股暴跌 → 全球投資者警覺 AI 泡沫可能真係要爆

### 對港股嘅傳導
1. **情緒傳導：** 韓股跌 → 全球風險偏好下降 → 港股跟跌
2. **板塊傳導：** 半導體股受壓（中芯、華虹等）
3. **資金傳導：** 外資從亞洲新興市場撤資
