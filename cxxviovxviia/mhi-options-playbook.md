## 🌊 VHSI 動態分析（核心指標深度解讀）

### VHSI 係咩？

VHSI（恒指波幅指數）= 市場對恒指未來 30 日波動嘅預期。概念等同美股嘅 VIX，但針對港股。

- **計算方式：** 基於恒指期權嘅報價，用類似 VIX 嘅方法編算
- **更新頻率：** 每 15 秒更新一次
- **查詢：** 富途搜「VHSI」、港交所官網、Investing.com

### VHSI 歷史參考（重要 baseline）

**2026年至今（截至5月）：**
- 年內高位：22.55（1月30日）
- 年內低位：19.99
- 5月中旬：~21.5
- 年初至今變動：+18.81%

**近年年終收市水平：**
| 年份 | VHSI 年終 | 恒指年終 | 備註 |
|------|----------|---------|------|
| 2024 | 22.35 | — | 高波動年 |
| 2025 | 18.98 | — | 相對平靜 |
| 2026 YTD | ~21.5 | 27,387 | 回升高波動 |

**歷史極端水平：**
| 情境 | VHSI 水平 | 你應該做嘅嘢 |
|------|----------|-------------|
| 超級平靜（2025年般） | 15-18 | ❌ 唔好開新倉，期權金太薄 |
| 正常波動 | 18-25 | ✅ 正常操作 |
| 升溫 | 25-35 | ✅✅ 積極開倉，期權金貴 |
| 恐慌（2020年般） | 35-50+ | ⚠️ 小心，雖然期權金好貴，但代表市場預期大波動 |
| 金融危機 | 50+ | 🛑 唔好新開，只管好現有倉位 |

### VHSI vs VIX 嘅關係

- **相關性：** 中高度正相關（通常 0.6-0.8）
- **VIX 領先 VHSI：** 美股隔夜大波動 → 第二日港股 VHSI 會跟
- **但唔完全同步：** 港股有自己嘅因素（A股、中國政策、南向資金）

**實戰用法：**
```
美股 VIX 隔夜急升 > 25 → 聽朝 VHSI 大概率升 → 可以趁高開 short
美股 VIX 隔夜暴跌 < 15 → 聽朝 VHSI 大概率跌 → 唔好開新 short
兩者背馳（VIX 升但 VHSI 跌）→ 港股有自己因素撐住，留意本地消息
```

### VHSI 嘅季節性規律

| 時期 | VHSI 傾向 | 原因 | 你嘅策略 |
|------|----------|------|----------|
| 1月 | 偏高 | 年初重新佈局、兩會預期 | 開倉好時機 |
| 2-3月 | 波動大 | 兩會、業績期開始 | 留意事件，等明朗再開 |
| 4月 | 偏高 | 港股業績高峰期 | 可以開，但揀行使價要保守啲 |
| 5-6月 | 中性偏降 | 「Sell in May」效應 | 正常操作 |
| 7-8月 | 偏低 | 暑假淡季、成交縮 | 唔好勉強開，期權金可能薄 |
| 9-10月 | 開始升 | 美股Q3業績、第四季展望 | 開始可以積極啲 |
| 11-12月 | 視乎年份 | 年尾粉飾櫥窗 / 挾倉 | 留意年尾特殊市況 |

### 用 VHSI 做 Position Sizing

**核心原則：VHSI 高 = 期權金貴 = 可以收多啲 = 但亦代表風險高咗**

```
VHSI > 30：每張收 $400-600+ → 可以保守啲張數（因為每張收入多）
VHSI 20-30：每張收 $200-400 → 正常張數
VHSI < 20：每張收 $100-200 → 要加張數先維持收入，但風險係回報低
```

**建議嘅動態調整：**
| VHSI 水平 | 保證金佔用上限 | 原因 |
|----------|--------------|------|
| > 30 | 40% | 波動大，留多啲 buffer |
| 20-30 | 50% | 正常操作 |
| 15-20 | 55-60% | 波動細，可以稍為進取（但期權金薄） |
| < 15 | 唔開倉 | 唔值得冒險 |

### VHSI 滾倉時機指標

**最佳滾倉時機：**
1. 現有倉位期權金跌到 < 25% 開倉價
2. **同時** VHSI 處於相對高位（> 22）→ 開新倉可以收貴啲

**避免滾倉時機：**
- VHSI 處於低位（< 18）→ 寧願等，唔好急住開新倉
- VHSI 正在急升中 → 等穩定再開（急升代表市場仲未 settle）

**VHSI 趨勢判斷：**
```
連續 3 日上升 + 每日升 > 5% → 波動升溫中，開倉好時機但要保守行使價
連續 3 日下跌 + 每日跌 > 3% → 波動降溫中，可能快到低位，準備開倉
VHSI 單日飆升 > 20% → 通常係突發事件，等 2-3 日穩定先決定
```

### VHSI 同你嘅風險管理

**關鍵公式：**
```
你嘅 Short 倉浮虧 ≈ VHSI 升幅 × Delta × 張數 × 每點價值
```

當 VHSI 急升：
1. 你嘅期權金浮虧會擴大（即使恒指冇點郁）
2. Margin requirement 可能會被 broker 調高
3. 兩樣嘢夾埋會令 margin ratio 快速恶化

**所以：**
- Margin ratio < 2.0x 嘅時候，要特別留意 VHSI 動態
- VHSI 突破 30 → 即刻計一次最壞情況嘅 margin 需求
- 設定 alert：VHSI > 25、VHSI > 30、VHSI 單日升 > 15%

## 📐 引申波幅（Implied Volatility, IV）— 期權定價嘅核心密碼

### IV 係咩？

引申波幅（Implied Volatility, IV）= 市場「預期」恆指未來會有幾波動，呢個預期已經反映喺期權價格入面。

```
簡單講：
- IV 高 = 市場覺得未來會好波動 = 期權貴
- IV 低 = 市場覺得未來會好平靜 = 期權平
```

**你做緊 short strangle，本質上就係「賣波幅」— IV 高嘅時候賣，等 IV 跌返就賺錢。**

### IV 同 VHSI 嘅關係

**VHSI 就係由 IV 計出嚟嘅。**

VHSI 嘅計算方式：攞恆指期權（近月+次月，近價嘅 Call 同 Put）嘅報價 → 反推出每個行使價嘅 IV → 加權平均 → 就係 VHSI。

```
關係圖：

恆指期權報價 → 反推 IV（每個行使價都有自己嘅 IV）→ 加權平均 → VHSI
                     ↑                                    ↑
              個別期權嘅引申波幅                     整體市場波幅預期
```

**所以：**
- VHSI 升 → 代表整體 IV 升 → 你嘅期權倉浮虧（因為期權貴咗）
- VHSI 跌 → 代表整體 IV 跌 → 你嘅期權倉浮盈（因為期權平咗）
- **VHSI 係 IV 嘅「平均代表」，但個別期權嘅 IV 可以偏離 VHSI**

### 點解個別期權 IV 唔等於 VHSI？

有三個原因：

**1. 波幅微笑 / 波幅歪斜（Volatility Skew/Smile）**

```
行使價        IV
---------------
Deep OTM Put   28%  ← 愈深嘅 put，IV 愈高（恐慌溢價）
OTM Put        24%
ATM（平值）     21%  ← 最接近 VHSI 嘅水平
OTM Call       19%
Deep OTM Call  17%  ← 愈深嘅 call，IV 愈低
```

點解？
- Put 邊 IV 高：市場願意付溢價買保險（恐慌情緒）
- Call 邊 IV 低：市場唔太擔心升，賣 call 嘅人多
- 呢個「一邊高一邊低」嘅形態叫 Volatility Skew

**對你嘅意義：** 你嘅 deep OTM put IV 可能高過 VHSI 幾個百分點 → 你賣嘅時候收到嘅期權金比 VHSI 反映嘅更豐厚。呢個係你嘅優勢。

**2. 時間結構（Term Structure）**

```
到期日     IV
-----------
1個月       22%  ← 短期波動受近期事件影響
2個月       21%
3個月       20%  ← 中期通常較平穩
6個月       19%
```

- 近月 IV 通常高過遠月（近期不確定性大）
- 但如果有重大事件喺遠月（例如選舉），遠月 IV 可以高過近月 → 呢個叫「倒掛」
- **倒掛係罕見訊號** = 市場預期遠期有大事發生

**對你嘅意義：** 賣近月期權嘅 IV 通常高過遠月 → 收得多啲但時間短。賣遠月 IV 低啲但收得耐。你而家做緊嘅「近月+季月」組合已經係一種平衡。

**3. 供求失衡**

- 某個行使價突然有大量買盤 → IV 被推高（即使 VHSI 冇點變）
- 某個行使價突然有大量賣盤 → IV 被壓低
- **呢個就係點解要睇個別行使價嘅 IV，唔好淨睇 VHSI**

### IV 點樣影響你嘅盈虧

```
你開倉時 IV = 22%（收咗 100 點期權金）

情景 A：IV 跌到 18%（VHSI 回落）
  → 期權金跌到 ~60 點 → 浮盈 +40 點 ✅
  → 原因：波幅預期降溫，時間值加速消耗

情景 B：IV 升到 28%（VHSI 飆升）
  → 期權金升到 ~180 點 → 浮虧 -80 點 🔴
  → 原因：波幅預期升溫，期權被重新定價

情景 C：IV 不變，到期日接近
  → 期權金慢慢跌到 ~20 點 → 浮盈 +80 點 ✅
  → 原因：時間值消耗（Theta）
```

**最理想：IV 高嘅時候開倉（賣貴），IV 跌嘅時候持有（賺波幅收縮 + 時間值）。**

### IV Rank 同 IV Percentile（進階參考）

```
IV Rank = 而家嘅 IV 喺過去一年嘅位置（0-100%）
  IV Rank > 50% = IV 偏高 → 適合 short
  IV Rank < 20% = IV 偏低 → 唔好 short

IV Percentile = 過去一年有幾多日嘅 IV 低過而家
  IV Percentile 80% = 過去 365 日有 80% 嘅時間 IV 低過而家
  = 而家 IV 偏高 → 適合 short
```

**點睇：** 富途期權鏈有得顯示 IV 同歷史波幅（HV）對比。

### IV vs 歷史波幅（HV）— 兩個要一齊睇

```
IV = 市場「預期」未來嘅波動（forward-looking）
HV = 過去「實際」發生咗嘅波動（backward-looking）
```

| 情況 | IV vs HV | 解讀 | 你要做嘅嘢 |
|------|----------|------|----------|
| IV > HV 好多 | 市場預期比歷史波動大 | 期權偏貴 | ✅ 適合 short（你收貴期權金） |
| IV ≈ HV | 預期同實際差唔多 | 期權合理定價 | 正常操作 |
| IV < HV 好多 | 市場低估咗波動 | 期權偏平 | ⚠️ 唔好 short，可能會被突發波動打穿 |

### 實戰 Check：開倉前嘅 IV 快速判斷

```
1. VHSI 幾多？> 20 先考慮開倉
2. 你要開嘅行使價，IV 幾多？高過 VHSI 就好（有 skew 溢價）
3. IV Rank > 50%？係就更好（IV 偏高位）
4. IV > HV？係就更好（市場預期比歷史大，你賣貴）
5. 全部 ✅ → 開倉信心強
```

### 一句總結

> VHSI 係整體波幅預期嘅溫度計，IV 係每個期權自己嘅波幅標籤。VHSI 升跌影響你嘅整體倉位浮盈虧，但個別行使價嘅 IV 先決定你開倉收幾多錢。**做 short 就係賣 IV — 高賣低買，同時間做朋友。**

## Open Interest (OI) — 未平倉合約完全解讀

### 基本概念

OI（Open Interest）= 市場上仲未平倉/結算嘅合約總數。每次有人開新倉（買+賣配對），OI +1。每次有人平倉，OI -1。

- 新買家 + 新賣家 = 開新倉 → OI +1
- 舊買家平倉 + 舊賣家平倉 = 平倉 → OI -1
- 新買家取代舊買家 = 轉手 → OI 不變

### 價格 + OI 四象限（最核心分析框架）

| 組合 | 價格 | OI | 點解 | 後市解讀 |
|------|------|------|------|---------|
| ① | 升 | 升 | 新資金入場做多，買盤強 | ✅ 升勢健康，趨勢可持續 |
| ② | 升 | 跌 | 舊倉平倉獲利，短倉止損 | ⚠️ 升勢乏力，可能快見頂 |
| ③ | 跌 | 升 | 新資金入場做空，賣盤強 | 🔴 跌勢健康，趨勢可持續 |
| ④ | 跌 | 跌 | 舊倉平倉，長倉止損離場 | ⚠️ 跌勢減弱，可能快見底 |

記法：價格同 OI 同方向 = 趨勢 confirm，可持續。背馳 = 趨勢減弱，留意轉向。

### 不同市況下嘅 OI 解讀

**趨勢市（單邊升）：**
- OI 持續增加 = 新資金不斷入場，趨勢強勁 ✅
- 你嘅意義：short put 有利，但 OI 極高 → 容易出現挾倉
- 留意：OI 升到極高水平 → 一旦反轉會好急

**趨勢市（單邊跌）：**
- OI 持續增加 = 新空軍入場，跌勢未完 🔴
- 你嘅意義：short put 風險增加，要特別留意 buffer
- 留意：如果同時 VHSI 急升 → 雙重壓力

**橫行/窄幅上落：**
- OI 增加 + 價格唔郁 = 大量資金累積緊，醞釀突破
- 你嘅意義：strangle 最開心，但要有心理準備突破後會好急
- 留意方向：突破嗰邊嘅 OI 邊多 = 邊個方向機會大

**恐慌/急跌後：**
- 價格暴跌 + OI 急跌 = 恐慌性平倉，長倉止損離場
- 呢個係見底訊號之一 ⚠️ → 唔好再追空
- 你嘅意義：put 倉仲 OTM 嘅話唔好 panic 平，等反彈

**急升後：**
- 價格暴升 + OI 跌 = 獲利盤平倉，動力減弱
- 可能見頂訊號 ⚠️
- 你嘅意義：short call 接近 ITM 嘅話，呢個係止損最後窗口

### 期權操作嘅 OI 實戰用法

**1. 搵支持/阻力（期權 OI 分布）**

期權最大 OI 集中嘅行使價 = 市場嘅「磁鐵位」

例子：
- Put 最大 OI：22,000（大量人買咗保護）
- Call 最大 OI：29,000（大量人賣咗 covered call）
- 解讀：22,000 係強支持，29,000 係強阻力
- 恆指好大機會喺 22,000 - 29,000 區間運行

點睇：富途期權鏈 → 睇 Put OI 同 Call OI 最大嘅幾個行使價

**2. 判斷結算日挾倉**

結算日前 1-2 日：恆指接近某個大量 OI 嘅行使價 → 做市商要大量對沖 → 價格會被「拉埋」去嗰個位
- 你嘅意義：行使價附近有大量 OI → 結算日前波動會加劇

**3. OI 異動偵測**

| 異動 | 可能原因 | 你要做嘅嘢 |
|------|---------|---------|
| OI 單日暴增 > 20% | 大戶部署 | 留意方向，可能快有趨勢 |
| OI 單日暴跌 > 15% | 大規模平倉 | 趨勢可能結束 |
| Put OI 急增 | 市場恐慌升溫 | VHSI 會跟升 → 倉浮虧增加 |
| Call OI 急增 | 市場樂觀/挾淡倉 | 留意 short call 倉位 |

### 期指 OI vs 期權 OI（兩樣都要睇）

| | 期指 OI | 期權 OI |
|---|---|---|
| 睇咩 | 大戶方向部署 | 支持/阻力位 + 市場預期 |
| 喺邊度睇 | 富途期貨頁面 / HKEX 每日統計 | 富途期權鏈 |
| 幾時睇 | 每日收市後對比前日 | 開倉前 + 結算日前 |
| 點用 | 判斷趨勢強弱 | 揀行使價 + 判斷區間 |

### OI 數據來源

| 來源 | 睇到咩 |
|------|--------|
| 富途牛牛 → 期貨 | 期指即時 OI、每日變化 |
| 富途牛牛 → 期權鏈 | 每個行使價嘅 Put/Call OI |
| HKEX 每日統計 | 恒指期貨 OI 總數、按經紀席位分佈 |
| AASTOCKS | 期貨 OI 排行、未平倉淨數 |

### 一句總結

OI 係「資金嘅腳印」。價格話俾你知而家發生緊咩，OI 話俾你知背後有幾多資金支持緊呢個趨勢。兩個一齊睇，先至睇到全貌。

## 🎯 入場規則（幾時開倉）

### 開倉 Checklist（每次開倉前逐項過）

**必要條件（全部 ✓ 先開）：**
- [ ] VHSI > 18
- [ ] 期權金 > 過去 30 日平均

- [ ] 恒指唔喺歷史高位/低位嘅邊緣
- [ ] 保證金佔用 < 帳戶 50%
- [ ] 已有止損計劃

### 行使價選擇

**Put 邊（防守下限）：**
```
短期（1個月內）：行使價 = 現價 × 0.90 ~ 0.92（低 8-12%）
中期（2-3個月）：行使價 = 現價 × 0.86 ~ 0.90（低 10-14%）
長期（季月）：  行使價 = 現價 × 0.82 ~ 0.88（低 12-18%）
```

**Call 邊（防守上限）：**
```
短期：行使價 = 現價 × 1.08 ~ 1.12（高 8-12%）
中期：行使價 = 現價 × 1.10 ~ 1.16（高 10-16%）
長期：行使價 = 現價 × 1.15 ~ 1.25（高 15-25%）
```

**例子（恒指 25,642）：**
| 方向 | 短期行使價 | 中期 | 長期 |
|------|-----------|------|------|
| Put | 22,600-23,100 | 22,100-23,100 | 20,500-22,600 |
| Call | 27,700-28,700 | 28,200-29,700 | 29,500-32,100 |

### 張數分配

```
總保證金預算 = 帳戶資金 × 45%（保守）~ 60%（進取）

每張保證金 ≈ $13,000-15,000（short put/call MHI）

張數 = 總保證金預算 ÷ $15,000

例：帳戶 $300K × 50% = $150K ÷ $15K = 10 張
```

**Put : Call 比例：**
- 看好後市：Put 6 : Call 4
- 中性：Put 5 : Call 5
- 看淡後市：Put 4 : Call 6

## 🚪 離場規則（幾時平倉）

### Take Profit（止賺）

| 情況 | 行動 |
|------|------|
| 期權金跌到開倉價嘅 **20-25%** | ✅ 平倉鎖定利潤（已賺 75-80%） |
| 期權金跌到 **< 5 點** | ✅ 即時平倉（幾乎無值，釋放保證金更重要） |
| 距到期仲有 2 週 + 已賺 > 70% | ✅ 平倉，開下月新倉（時間值換空間） |
| 季月 deep OTM 已賺 > 50% + 距到期仲有 2 個月+ | ⚠️ 可以等，但考慮平倉再開更遠期 |

**核心原則：唔好貪到最後一滴。賺咗 75-80% 就走，釋放保證金滾下一輪。**

### Stop Loss（止蝕）

**硬性止損（必須執行）：**

| 情況 | 止損觸發 | 行動 |
|------|---------|------|
| 期權金升穿開倉價 **2 倍** | ⛔ 即時平倉 | 例：開 100 點，現價 > 200 點 |
| 恒指跌穿 put 行使價 **+ 200 點** | ⛔ 平 put 倉 | 例：put 23,000，恒指跌到 23,200 以下 |
| 恒指升穿 call 行使價 **- 200 點** | ⛔ 平 call 倉 | 例：call 28,000，恒指升到 27,800 以上 |
| VHSI 突然飆升 > 50% | ⛔ 審視所有倉位 | 可能需要平部分倉 |
| Margin call 風險 | ⛔ 即時減倉 | 帳戶淨值跌近維持保證金 |

**軟性止損（觀察但唔一定即刻行動）：**
- 恒指連續 3 日單方向移動超過 1%
- 你嘅倉位浮虧 > 開倉時收取期權金嘅 1.5 倍
- 重大突發新聞（地緣政治、金融危機等）

### 滾倉規則

**每個月結算日前 5-7 日：**
1. 檢視現月倉位
2. 期權金已跌到 < 20% 開倉價 → 平倉鎖利
3. 同時開下月新倉（根據當時 VHSI 同恒指位置揀行使價）
4. 季月倉可以繼續持有（除非觸發止損）

## ⚡ 突發事件應變

### 黑天鵝 / 極端市況 protocol

**情況 A：恒指單日暴跌 > 1,000 點**
1. 唔好 panic — 你嘅 put 有 buffer
2. 即刻 check：put 行使價 vs 現價，仲有幾多 buffer
3. 如果 buffer < 500 點 → 認真考慮止損
4. 如果 buffer > 1,000 點 → 觀察，唔好輕舉妄動
5. 同時 check：margin 水平，夠唔夠維持
6. 如果有浮動資金 → 可以考慮加 long put 做保護（對沖）

**情況 B：恒指單日暴升 > 1,000 點**
1. Check call 倉 buffer
2. 如果 call 快變 ITM → 止損
3. 如果仍然 OTM > 1,000 點 → 持有觀察

**情況 C：VHSI 突然飆升 > 40**
1. 你嘅現有倉位會浮虧（期權金被推高）
2. 唔好因為浮虧而 panic 平倉 — **浮虧唔係實虧**
3. 等波動回落，期權金會回落
4. 但要 check margin 夠唔夠撐
5. 呢個時候反而可以考慮開新 short（期權金貴！）

**情況 D：超級黑天鵝（恒指暴跌 > 3,000 點）**
1. 所有 put 倉會深度 ITM，巨額虧損
2. 即刻 check margin，防強平
3. 盡量止損最危險嘅倉（最貼價嘅 put）
4. 如果保證金撐得住 → 可以等反彈（但要有心理準備可能繼續跌）
5. 記住：你嘅 call 倉呢個時候會大幅獲利（call 變得更 OTM，期權金歸零）

### 期指 + 期權三大配合策略

#### 配合 1：期指做對沖（保護期權倉）

```
情景：你開咗 6月 Put 22,400 × 4，恆指突然跌到 24,000

```

**使用時機：**
- 恆指急跌逼近你嘅 Put 行使價（buffer < 500 點）

**風險：**
- 恆指反彈 → 期指短倉會虧（但期權倉同時好轉）
- 雙重保證金佔用
- 要主動平期指倉，唔好似期權咥可以等到到期

#### 配合 2：期指食方向（期權之外的額外利潤）

期權倉：維持 short strangle（收租）
期指動作：Long 1-2 張 MHI 期指

結果：
  升中 → 期權倉正常收租 + 期指長倉賺方向利潤
  跌 → 期權倉正常收租，期指長倉虧（但有期權金墊底）

雙管齊下：收租 + 炒方向 = 收入最大化
```

**使用時機：**
- 你對方向有強烈觀點（例如 FOMC 後明確方向）
- VHSI 唔高唔低（期權金一般），想加多一層利潤
- 保證金充裕（Margin Ratio > 2.5x）

**風險：**
- 方向判斷錯 → 期指虧損（但期權金可以部分抵消）
- 增加持倉風險

#### 配合 3：期指開路，期權收尾

```
情景：恆指跌到支持位 26,000，你認為會反彈

Step 1：Long 1張 MHI 期指（博反彈）
Step 2：如果真係反彈到 27,000 → 平期指食利潤
Step 3：同時喺高位開 short call（期權金貴咗，收多啲）

期指負責食快浪，期權負責收慢錢
```

**使用時機：**
- 恆指到達明確支持/阻力位
- 你想短炒一波但唔想持有期指過夜
- 賺完期指利潤後順勢開期權倉

### 期指操作紀律

```
⚠️ 期指唔同期權，冇「到期歸零」嘅保護

1. 每張期指必須設止損（建議：200-300 點 = $2,000-3,000 MHI）
2. 唔過夜持倉（除非你好有把握）— 夜期波動可以好大
3. 最多同時持有 2 張期指（配合期權倉已經夠）
4. 期指保證金獨立計算，唔好同期權保證金撈亂
5. 記住：期指係輔助工具，主菜仍然係期權 strangle
```

## 市場運作與潛規則

### 做市商（Market Maker）— 幕後最重要嘅角色

做市商係邊個？
- 港交所認可嘅機構（例如法巴、高盛、摩根等）
- 佢哋負責提供買賣報價，確保市場有流動性

做市商點賺錢？
- Bid-Ask Spread（買賣差價）
- 例如：買價 100 點，賣價 102 點，中間 2 點就係佢賺

做市商嘅對沖行為點影響你？
- 佢賣咗 Put 俾你 → 佢要買期指對沖（Delta Hedge）
- 如果恆指跌 → Put 嘅 Delta 變大 → 佢要買更多期指對沖
- 幾千張期指一齊對沖 → 推動恆指走勢
- 所以：期權 OI 大嘅行使價附近，做市商嘅對沖盤會形成「磁鐵效應」

### 挾倉（Short Squeeze）完全拆解

咩係挾倉？
- 有人做咗空（short），價格突然升，佢被逼買返平倉
- 買嘅動作再推高價格 → 更多空軍被逼平倉 → 價格再升 → 惡性循環

用一個故事講：
1. 大戶 A 覺得會跌 → Short 100 張 MHI（做空）
2. 突然利好消息出現（例如美國減息）
3. 恒指急升到 25,500
4. 大戶 A 開始虧損，保證金唔夠 → 被逼買返平倉
5. 佢一買 → 價格再升 → 另一個大戶 B 都被逼買返平倉
6. 惡性循環 → 恒指可能一兩日內升 1,000-2,000 點
7. 到最後所有空軍都平咗倉 → 無人再被逼買 → 升勢結束

邊啲人會做「挾倉」？

| 角色 | 動機 | 點做 |
|------|------|------|
| 大戶/基金 | 見到市場空倉太多，刻意買上去 | 集中大量買盤，推升價格觸發空軍止損 |
| 做市商 | 被動挾倉 — 對沖機制會自動買入 | 空軍止損平倉 = 買入，做市商要對沖都要買 |
| 散戶集體（罕見） | Reddit/WallStreetBets 模式 | 大量散戶同時買，但港股期指好難出現 |
| 結算日前「踩」 | 結算日挾淡倉收期權金 | 恆指接近大量 put OI 行使價時，刻意推升/推低令對家輸 |

挾倉嘅市場訊號（點樣提前察覺）：

⚠️ 挾倉前嘅蛛絲馬跡：
1. 空倉比例異常高（例如 Put OI / Call OI > 2:1）
2. 借貨利率飆升（代表好難借到貨做空）
3. 價格突然由低位急彈 + 成交量暴增
4. 連續幾日陰燭後突然出現大陽燭
5. OI 急跌 + 價格急升 = 空軍正在被「挾」緊

你作為期權操作者嘅影響：

| 情況 | 對你嘅 short 倉 | 你要做嘅嘢 |
|------|----------------|---------|
| 挾淡倉（升） | Short call 變 ITM 🔴 | 即刻止損 call 倉 |
| 挾好倉（跌） | Short put 變 ITM 🔴 | 即刻止損 put 倉 |
| 結算日前挾倉 | 行使價附近波動加劇 | 提前 2-3 日鎖利，唔好等到期 |
| 挾倉完結後 | 波動回落，VHSI 跌 | 可以考慮開新倉（期權金可能仲貴） |

### 大戶行為模式

| 大戶類型 | 特徵 | 點樣影響市場 |
|---------|------|------------|
| 對沖基金 | 槓桿高，止損嚴格 | 止損時會產生急劇波動 |
| 宏觀基金 | 睇大方向，持倉耐 | 長期趨勢嘅推手 |
| 內銀/中資 | 政策主導 | 兩會、減息等政策市會大舉入市 |
| 恒指調整基金 | 跟恒指成份股變動 | 成份股變動時會大量買賣 |
| 自營商 | 日內交易，速進速出 | 增加日內波動，但唔影響大方向 |

### 「聰明錢」vs「散戶錢」

聰明錢（Smart Money）嘅特徵：
- OI 大幅增加但價格唔點郁 = 靜靜部署
- 夜期出現異常大成交 = 可能預知消息
- 期權 Put OI 突然暴增 = 可能有人收到風要避險

散戶錢嘅特徵：
- 價格已經大升先追入 = 接火棒
- 成交量暴增但 OI 唔升 = 散戶互接，大戶已經走咗
- 社交媒體熱烈討論某個方向 = 通常係趨勢尾聲

### 結算日潛規則

結算日（每月倒數第二個交易日）：

1.「拉鋸」效應
   - 恆指會被「拉」向最大 OI 嘅行使價
   - 因為做市商要結算對沖盤
   - 例：Put 最大 OI 26,000 → 結算價好大機會喺 26,000 附近

2.「踩」遊戲
   - 大戶會故意推高/推低令對家嘅期權變 ITM/OTM
   - 如果你嘅 put 行使價 23,000，結算前恆指跌到 23,100
   - 大戶可能故意踩低多 200 點令你 ITM

3. 結算後「真空」
   - 結算完後，舊倉平晒 → 方向性突然消失
   - 第二日走勢可能完全唔同

### 夜期潛規則

夜期（17:15 - 03:00）：

1. 流動性低 → 少量資金就可以推動大波動
2. 大戶鍾意喺夜期「試水」→ 細注測試方向
3. 美股開市（21:30）係轉捩點 → 之後方向多數跟美股
4. 凌晨 2-3 點成交最淡 → 呢段時間嘅波動唔太可信
5. 夜期升跌幅度通常係日市嘅 30-50%

```
VHSI > 20？

### 平倉決策樹

```
期權金跌到 < 25% 開倉價？
├── Yes → ✅ 平倉鎖利
└── No → 期權金升穿 2x 開倉價？
         ├── Yes → ⛔ 止損
         └── No → 恒指逼近行使價？
                  ├── Yes（< 500 點 buffer）→ ⚠️ 考慮平倉
                  └── No → 持有，繼續觀察
```

### 保證金管理

```
帳戶淨值 / 佔用保證金 = Margin Ratio

> 3.0x → ✅ 安全，可以開新倉
2.0-3.0x → ⚠️ 唔好再加倉
1.5-2.0x → 🔴 考慮減倉
< 1.5x → ⛔ 即時減倉或補資金
```
